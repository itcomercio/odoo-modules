# Comodoo POS Screen Saver

Este módulo personaliza el salvapantallas (screensaver) del Punto de Venta (POS) de Odoo, sustituyendo el logo de Odoo por el logo de Comodoo.

## Características
- Sustitución automática del logo en el salvapantallas.
- Sin configuración adicional necesaria.
- Implementado mediante SCSS para una integración limpia.
